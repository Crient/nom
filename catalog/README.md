# Nom development catalog

`Nom_Dish_Catalog_Master_V1_Pilot25_SourcesVerified.xlsx` is the project copy
of the supplied master workbook, with four invalid descriptor cells cleared.
The original is backed up in `backups/` before that cleanup. It remains human editable. The runtime
catalog includes **all 201 canonical Dishes rows**, not just the pilot.

## Import and validation

After editing the source workbook, run:

```sh
npm run catalog:import
npm run catalog:check
npm test
npm run build
```

Import/check use Python 3's standard XLSX ZIP/XML reader and Node 22+. No Excel
package, network connection, workbook authoring tool, or runtime spreadsheet
dependency is required. Import validates candidates before writing outputs;
`catalog:check` compares every generated byte with a fresh conversion without
writing. `catalog:validate` also runs before the production build.

`Dishes!A4:S4` defines the required headers. Rows 5–205 map one-to-one, in order,
to `src/data/catalog/records.json`. Blank flavor/descriptor cells are omitted
from arrays; nonblank cells retain their source order. Pipe-delimited aliases
become arrays. Adventure levels become integers. All remaining columns are
preserved, including countryCode, notes, reviewStatus, validationStatus, and both
descriptions. Each record retains its sourceRow for tracing edits.

`Allowed_Values` supplies the generated `taxonomy.json`, checked against the
existing eight regions, five food types, six frozen flavors, descriptor IDs,
adventure levels 1–3, review statuses, and ISO country-code list. The importer
rejects invalid/missing fields, unknown IDs, duplicate dish IDs or tags, empty
preference flavors, and incomplete record counts. Unsupported workbook schemas
fail explicitly. It never silently discards or repairs a dish.

The other sheets remain QA/reference data. No production/pilot restrictions
written inside the workbook are applied to this development build.

## Runtime and recommendations

`src/data/dishes.js` enriches the generated records with country display names,
flags, and replaceable images. It does not filter or sort records. The existing
rules-based engine and its 35/30/20/15 weights remain unchanged; spreadsheet order
breaks ordinary score ties. Review status and descriptors never score.

Dish Matches still shows ranks 1–3; More Options still shows `results.slice(3,10)`.
All 201 dishes participate in ranking and resolve through the existing detail
route when a discovery session is present. Favorites continue to store canonical
IDs in shared Context, with versioned local persistence during development.

## Source review findings

- All 201 Dishes records have `reviewStatus: needs-review` and cached
  `validationStatus: OK`. Exactly 25 have an approved factual source in `Sources`;
  this does **not** imply that their dishes or images are approved.
- Removed invalid descriptor `crispy` from Dishes!L34 (chole-bhature), K42
  (koshari), K48 (arepa), and K153 (reuben-sandwich). No other workbook cells or
  metadata changed. The `crispy` preference flavors at I42 and I153 remain.
  No replacement descriptors were added. All 201 records now pass strict
  descriptor validation without exceptions; the taxonomy and scoring are unchanged.
- No duplicate IDs, zero-flavor dishes, malformed required fields, invalid
  country/region/food-type/flavor IDs, or invalid adventure levels were found.
- `ingestion-report.json` records the source SHA-256, counts, and the empty
  descriptor/preference-overlap list.

## Replaceable image assets

Ten existing local WebP dish photos are mapped by canonical ID in `dishImages`.
The other 191 records use the same small local SVG placeholder and carry
`imageStatus: placeholder`. Replace or add an entry in that image map to supply
a future real asset; canonical records, IDs, favorites, and scoring need no edits.

The workbook currently contains no direct image download URLs or runtime paths.
Its Wikimedia media-search pages are reference links only and never become image
sources. The original Images/Sources sheets remain intact in the copied workbook.
Image licensing and further factual verification were not performed in this task.

catalog. For noodles + spicy/comforting + adventurous + Southeast Asia, the new

Pancit Bihon (77), Num Banh Chok (77), Mì Quảng (70), Cao Lầu (70), Reshteh Polow
(70), and Rechta (70). These are engine outputs, not UI overrides.
